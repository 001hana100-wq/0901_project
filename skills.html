도구와 기술

기술 이름을 많이 나열하기보다 실제 문제에 어떻게 적용하고 어떤 결과를 만들었는지에 집중합니다.

Technical toolkit

사용 경험을 기준으로 정리한 기술 영역

01

Frontend

의미 있는 HTML 구조와 CSS Grid·Flexbox를 활용해 다양한 화면에 대응합니다. JavaScript와 TypeScript로 접근 가능한 사용자 상호작용을 구현합니다.

  • HTML5
  • CSS3
  • JavaScript
  • TypeScript
02

Framework

React의 컴포넌트와 상태 흐름을 바탕으로 반복 가능한 UI를 설계합니다. Next.js와 Vite 환경에서 프로젝트를 구성하고 성능을 점검합니다.

  • React
  • Next.js
  • Vite
03

Backend

Node.js 기반의 간단한 REST API를 구현하고 프론트엔드와 서버 사이의 데이터 흐름을 이해합니다.

  • Node.js
  • Express
  • REST API
04

Workflow

Git과 GitHub로 변경 사항을 관리하고, Figma와 문서를 활용해 디자이너·개발자 사이의 맥락을 연결합니다.

  • Git
  • GitHub
  • Figma
  • Notion

Principles

기술을 선택하고 사용하는 기준

접근성을 기본값으로

키보드 조작, 명확한 제목 구조와 충분한 색상 대비를 구현 초기부터 고려합니다.

모바일부터 유연하게

작은 화면을 기본으로 설계하고 콘텐츠가 자연스럽게 확장되는 반응형 구조를 만듭니다.

읽기 쉬운 코드

역할이 드러나는 이름과 단순한 구조를 사용해 다음 작업자가 쉽게 이해하도록 합니다.

필요한 만큼만

새로운 도구 자체보다 문제 해결에 필요한 복잡도인지 판단하고 선택합니다.
