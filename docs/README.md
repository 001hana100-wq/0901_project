# 개인 프로필 페이지 문서

HTML, CSS, JavaScript를 사용해 반응형 개인 프로필 페이지를 만들기 위한 문서입니다.

## 문서 목록

1. [프로젝트 기획 및 요구사항](./01-requirements.md)
2. [프로필 콘텐츠 작성 양식](./02-profile-content.md)
3. [화면 구성과 디자인 가이드](./03-design-guide.md)
4. [구현 가이드](./04-implementation-guide.md)
5. [테스트 체크리스트](./05-test-checklist.md)

## 프로젝트 목표

- 방문자가 프로필 소유자를 빠르게 이해할 수 있는 페이지를 만든다.
- 자기소개, 기술, 프로젝트, 경력 및 연락처를 명확하게 전달한다.
- PC, 태블릿, 모바일에서 자연스럽게 보이는 반응형 화면을 구현한다.
- 프레임워크 없이 HTML, CSS, JavaScript의 기본 기능을 활용한다.
- 접근성과 유지보수성을 고려한다.

## 권장 진행 순서

1. `01-requirements.md`에서 표시할 정보와 기능을 확정한다.
2. `02-profile-content.md`의 양식에 실제 프로필 정보를 작성한다.
3. `03-design-guide.md`를 참고해 레이아웃과 색상을 정한다.
4. `04-implementation-guide.md`에 따라 파일을 만들고 기능을 구현한다.
5. `05-test-checklist.md`로 화면과 기능을 점검한다.
