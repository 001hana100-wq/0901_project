# 개인 프로필 페이지

`docs` 폴더의 요구사항과 디자인 가이드를 바탕으로 만든 HTML, CSS, JavaScript 기반 다중 페이지 포트폴리오입니다.

## 페이지 구성

- `index.html`: 홈과 프로필 요약
- `about.html`: 자기소개, 강점과 일하는 방식
- `skills.html`: 기술별 활용 경험과 개발 원칙
- `projects.html`: 대표 프로젝트, 역할과 주요 기능

## 실행

저장소 루트의 `index.html`을 브라우저에서 열거나 저장소 루트를 정적 파일 서버로 실행합니다.

## 실제 정보로 교체할 항목

`index.html`에서 다음 예시 값을 검색해 변경합니다.

- `김민준`: 실제 이름
- `hello@example.com`: 실제 이메일
- `github.com/your-name`: 실제 GitHub 표시 주소
- `https://github.com/`: 실제 GitHub 링크
- 자기소개, 강점, 기술 및 프로젝트 내용

현재 프로필 이미지는 `assets/images/profile.jpeg`입니다. 다른 사진으로 변경할 때 같은 파일명을 사용하거나 `index.html`의 이미지 경로, 크기 및 대체 텍스트를 함께 수정합니다.

## 포함된 기능

- 반응형 단일 페이지 레이아웃
- 모바일 내비게이션
- 라이트/다크 테마 및 선택값 저장
- 현재 섹션 메뉴 표시
- 스크롤 등장 효과와 동작 감소 설정 지원
- 이메일 복사
- 푸터 연도 자동 표시
