# 1. 프로젝트 기획 및 요구사항

## 1.1 페이지 목적

개인 프로필 페이지는 방문자에게 프로필 소유자의 소개, 역량, 작업 경험과 연락 방법을 전달하는 단일 페이지 웹사이트입니다.

## 1.2 주요 방문자

- 채용 담당자 또는 협업을 검토하는 사람
- 프로젝트와 기술 역량에 관심 있는 개발자
- 프로필 소유자에게 연락하려는 방문자

## 1.3 콘텐츠 요구사항

실제 구현 전에 아래 항목의 내용을 준비합니다.

| 구역 | 필수 내용 | 선택 내용 |
|---|---|---|
| 홈 | 이름, 직무 또는 한 줄 소개, 프로필 사진 또는 대표 이미지 | 이력서 링크 |
| 소개 | 자기소개, 본인의 강점 | 관심 분야, 가치관, 취미 |
| 기술 | 보유 기술, 기술별 활용 내용 | 숙련도, 사용 기간 |
| 프로젝트 | 제목, 설명, 사용 기술, 본인 역할 | 이미지, 데모 및 GitHub 저장소 링크 |
| 경력/활동 | 기간, 소속, 역할 | 주요 성과 |
| 연락처 | 이메일, GitHub | 전화번호, LinkedIn, 블로그 |

개인정보 보호를 위해 전화번호, 주소 등 민감한 정보는 꼭 필요한 경우에만 공개합니다.

## 1.4 화면 섹션

페이지는 다음 순서로 구성합니다.

1. 헤더 및 내비게이션
2. 히어로 영역(이름과 핵심 소개)
3. 자기소개와 강점
4. 보유 기술
5. 프로젝트
6. 경력 또는 활동(선택)
7. 연락처, 이메일 및 GitHub
8. 푸터

콘텐츠가 없는 섹션은 빈 상태로 두지 않고 화면에서 제외합니다.

## 1.5 기능 요구사항

### 필수 기능

- 내비게이션 클릭 시 해당 섹션으로 이동
- 모바일 화면에서 내비게이션 메뉴 열기/닫기
- 외부 링크를 새 탭에서 안전하게 열기
- 현재 연도를 푸터에 자동 표시

### 선택 기능

- 라이트/다크 테마 전환 및 선택값 저장
- 프로젝트 기술별 필터링
- 스크롤 위치에 따른 현재 메뉴 표시
- 요소가 화면에 들어올 때 가벼운 등장 효과
- 이메일 주소 복사 버튼

## 1.6 비기능 요구사항

- 최신 Chrome, Edge, Firefox, Safari에서 주요 기능이 동작해야 한다.
- 320px 너비의 모바일 화면부터 큰 데스크톱까지 대응한다.
- JavaScript가 꺼져도 핵심 콘텐츠를 읽을 수 있어야 한다.
- 제목 구조와 시맨틱 태그를 사용해 접근성을 확보한다.
- 이미지에 대체 텍스트를 제공하고 키보드로 모든 기능을 사용할 수 있게 한다.
- 불필요하게 큰 이미지와 라이브러리를 사용하지 않는다.

## 1.7 완료 기준

- 모든 필수 섹션에 실제 콘텐츠가 표시된다.
- 메뉴와 링크에 깨진 동작이 없다.
- 모바일과 데스크톱에서 콘텐츠가 겹치거나 잘리지 않는다.
- 브라우저 개발자 도구 콘솔에 오류가 없다.
- 테스트 체크리스트의 필수 항목을 모두 통과한다.
