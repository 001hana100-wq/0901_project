# 3. 화면 구성과 디자인 가이드

## 2.1 디자인 방향

- 키워드: 단정함, 신뢰감, 읽기 쉬움
- 핵심 정보가 장식보다 먼저 보이도록 한다.
- 강조색은 버튼, 링크, 주요 제목 등 필요한 곳에만 사용한다.
- 카드, 그림자와 애니메이션은 일관되고 절제된 수준으로 적용한다.

## 2.2 기본 레이아웃

- 콘텐츠 최대 너비: `1120px`
- 좌우 여백: 모바일 `20px`, 태블릿 이상 `32px`
- 섹션 상하 여백: 모바일 `64px`, 데스크톱 `96px`
- 헤더: 화면 상단에 고정하거나 일반 흐름에 배치
- 프로젝트: 모바일 1열, 태블릿 2열, 넓은 화면 3열 카드 구성

```text
┌────────────────────────────────────┐
│ 로고/이름             내비게이션  │
├────────────────────────────────────┤
│       이름 · 직무 · 소개 · CTA    │
├────────────────────────────────────┤
│ 소개                               │
├────────────────────────────────────┤
│ 기술                               │
├────────────────────────────────────┤
│ 프로젝트 카드                      │
├────────────────────────────────────┤
│ 경력/활동                          │
├────────────────────────────────────┤
│ 연락처                             │
├────────────────────────────────────┤
│ 푸터                               │
└────────────────────────────────────┘
```

## 2.3 권장 디자인 토큰

CSS 변수로 정의해 페이지 전체에서 재사용합니다.

```css
:root {
  --color-bg: #f8fafc;
  --color-surface: #ffffff;
  --color-text: #0f172a;
  --color-muted: #475569;
  --color-primary: #2563eb;
  --color-primary-hover: #1d4ed8;
  --color-border: #e2e8f0;

  --font-sans: "Pretendard", "Noto Sans KR", system-ui, sans-serif;
  --radius-sm: 8px;
  --radius-md: 16px;
  --shadow-card: 0 12px 30px rgba(15, 23, 42, 0.08);
}
```

색상은 예시이며 프로필의 성격에 맞게 변경할 수 있습니다. 일반 텍스트와 배경은 충분한 명도 대비를 유지합니다.

## 2.4 타이포그래피

- 페이지 제목: `clamp(2.5rem, 7vw, 5rem)`
- 섹션 제목: `clamp(1.75rem, 4vw, 2.5rem)`
- 본문: `1rem` 이상, 줄 높이 `1.6` 이상
- 긴 문장은 한 줄이 지나치게 길어지지 않도록 약 `65ch`로 제한
- 중요도는 글자 크기와 굵기로 표현하고 색상에만 의존하지 않기

## 2.5 반응형 기준

콘텐츠에 따라 조정하되 다음 기준을 시작점으로 사용합니다.

```css
/* 기본: 모바일 */

@media (min-width: 768px) {
  /* 태블릿 */
}

@media (min-width: 1024px) {
  /* 데스크톱 */
}
```

고정 높이는 가급적 피하고, 이미지에는 `max-width: 100%`와 적절한 `aspect-ratio`를 적용합니다.

## 2.6 상태 디자인

- 링크와 버튼에는 `hover`, `focus-visible`, `active` 상태를 제공한다.
- 키보드 초점 표시를 제거하지 않는다.
- 비활성 기능은 색상뿐 아니라 속성과 문구로도 구분한다.
- 애니메이션은 짧게 유지하고 `prefers-reduced-motion` 설정을 존중한다.
