# 5. 테스트 체크리스트

## 4.1 콘텐츠

- [ ] 이름, 직무, 소개 문구가 실제 정보로 작성되어 있다.
- [ ] 기술과 프로젝트 설명에 임시 문구가 남아 있지 않다.
- [ ] 이메일과 외부 프로필 주소가 정확하다.
- [ ] 맞춤법과 문장 표현을 확인했다.
- [ ] 공개하면 안 되는 개인정보가 포함되지 않았다.

## 4.2 화면과 반응형

- [ ] 320px 너비에서 가로 스크롤이 생기지 않는다.
- [ ] 모바일 메뉴가 콘텐츠를 부자연스럽게 가리지 않는다.
- [ ] 태블릿과 데스크톱에서 여백과 정렬이 자연스럽다.
- [ ] 텍스트 확대 시 콘텐츠가 겹치거나 잘리지 않는다.
- [ ] 이미지 비율이 깨지지 않고 대체 텍스트가 있다.
- [ ] 긴 프로젝트 제목과 설명도 카드 밖으로 넘치지 않는다.

권장 점검 너비: `320px`, `375px`, `768px`, `1024px`, `1440px`.

## 4.3 기능

- [ ] 모든 내비게이션 링크가 올바른 섹션으로 이동한다.
- [ ] 모바일 메뉴를 열고 닫을 수 있다.
- [ ] 메뉴 버튼의 `aria-expanded` 값이 상태와 일치한다.
- [ ] 외부 링크가 정확한 주소로 이동한다.
- [ ] 푸터 연도가 현재 연도로 표시된다.
- [ ] 선택 기능(테마, 필터 등)이 새로고침 후에도 의도대로 동작한다.
- [ ] 브라우저 콘솔에 JavaScript 오류가 없다.

## 4.4 접근성

- [ ] 키보드의 `Tab` 키만으로 모든 링크와 버튼에 접근할 수 있다.
- [ ] 현재 포커스 위치가 시각적으로 보인다.
- [ ] 본문 바로가기 링크가 동작한다.
- [ ] 제목 단계가 `h1`부터 순서대로 구성되어 있다.
- [ ] 폼이 있다면 모든 입력 요소에 연결된 레이블이 있다.
- [ ] 텍스트와 배경의 색상 대비가 충분하다.
- [ ] 색상만으로 정보나 상태를 구분하지 않는다.
- [ ] 동작 감소 설정에서 불필요한 애니메이션이 줄어든다.

## 4.5 품질과 성능

- [ ] HTML, CSS 파일에 명백한 문법 오류가 없다.
- [ ] 사용하지 않는 스타일과 스크립트를 제거했다.
- [ ] 이미지 크기를 화면 용도에 맞게 최적화했다.
- [ ] 이미지에 가능하면 `width`와 `height`를 지정했다.
- [ ] 페이지 최초 표시를 막는 불필요한 스크립트가 없다.
- [ ] Chrome, Edge, Firefox 또는 Safari 중 둘 이상의 브라우저에서 확인했다.

## 4.6 배포 전 최종 확인

- [ ] 로컬 파일 경로나 개인 개발 환경에만 존재하는 주소가 없다.
- [ ] 파일명 대소문자가 실제 참조와 일치한다.
- [ ] 깨진 링크와 누락된 이미지가 없다.
- [ ] 페이지 제목과 설명 메타 태그가 작성되어 있다.
- [ ] 대표 이미지와 파비콘을 사용할 경우 경로가 정확하다.
